# Legacy Old Files

This directory preserves unsupported historical material that is useful for reference but is not part of the maintained batch-first Aspen workflow.

- `archive/`: the previous archived Aspen artifacts, COM probes, and historical experiment scripts.
- `manual_test_probes/`: one-off scripts that may touch live Aspen, COM, registry state, or root-level files and are intentionally outside normal pytest collection.
- `legacy_docs/`: old plans, investigations, and research notes superseded by the maintained docs under `docs/`.

Generated runtime/cache output should stay ignored and should not be added here unless it is intentionally preserved as a small reference artifact.
